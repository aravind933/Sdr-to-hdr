Build steps
1. Install Android Studio (current stable) with Android SDK 34.
2. File > Open > select this Sdr2Hdr folder. Accept the prompt to sync / create the Gradle wrapper.
3. Build > Build APK(s). The debug APK appears in app/build/outputs/apk/debug/.
   Or connect an Android 13+ phone and press Run.
Requires: Android 13+ (API 33), a device with an HEVC Main10 encoder and OpenGL ES 3.0.
